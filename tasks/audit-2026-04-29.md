# Seatable Platform Audit -- 2026-04-29

Persona: Brazilian restaurant owner, word-of-mouth arrival, zero patience
Surfaces tested: Desktop web, mobile web (390x844), API layer, AI flows

## CRITICAL (7)

C1 - Site defaults to English. Every public page renders English by default. Language toggle exists but requires the user to find it. Dealbreaker for Brazilian-first market. Fix: Default i18n to pt-BR.

C2 - Pricing shows USD + English plan names. Live: dollar97/dollar297/dollar597, STARTER/GROWTH/ENTERPRISE. Should be R/R.497/R.997, Essencial/Profissional/Enterprise.

C3 - Booking confirmation is a dead-end English error. /book/cantina-bella-vista/confirmed loaded directly shows: No reservation details found. Make a Reservation -- all English, zero branding. Fix: Render Sua reserva foi confirmada via sessionStorage or DB token.

C4 - Login page is 100% English. Welcome back, Continue with Google, all form labels, left panel. Fix: Wire through i18n; Google button = Continuar com o Google.

C5 - Get Started CTA in navbar has no href. Button does nothing. Fix: Wire to /demo/setup.

C6 - Proactive comms cron is completely hollow. api/cron/proactive-comms.js finds opportunities, logs them, stops. No message sent. No DB write. Runs every Sunday doing nothing visible. Fix: Implement proactive_comms_queue table, surface in Manager AI panel, send via WhatsApp.

C7 - Morning briefing MAX_RESTAURANTS = 3 hard cap. Only 3 restaurants per cron run. With 4+ on platform most get nothing. Fix: Process all or implement cursor-based queue.
