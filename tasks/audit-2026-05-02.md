## HIGH (4)

### H1 — cron_runs table missing from prod
**Confirmed via /api/cron/health response: "cron_runs table may not exist yet."**
- 43 cron files write to cron_runs via logCronRun() / logCronError()
- /api/cron/health.js reads it for health-status checks
- /api/cron/health-alert.js (daily 10am UTC) skips alerts because of "DB unavailable" (the original M8 false flag in the previous audit was actually THIS bug)
- Result: 28/28 jobs report status="never_run". Zero observability. We cannot detect a silently-failing cron.
- Slipped past audit-migrations-applied because no migration file declares CREATE TABLE cron_runs (the audit only probes tables it can find a CREATE statement for).
- **Fix**: write supabase/migrations/20260502_cron_runs.sql + apply.

### H2 — Dashboard revenue widgets display USD ($) for Brazilian restaurants
- "RECEITA POR TAMANHO DE MESA" shows: \/couvert, \/mesa
- "PREVISÃO DE RECEITA" shows: \,988 / 7 dias, \,100/day
- The landing page pricing correctly shows R/R.497/R.997 (cascade from C1 fix)
- But the dashboard widgets are using $ — currency lookup probably defaults to USD when restaurant.country != Brazil mapping
- **Fix**: trace currencyFromLanguage / restaurant.country → currency mapping in RevenueByPartySizeWidget + RevenueStatsWidget

### H3 — ProactiveCommsPanel cards display raw English suggested_action
Card subtitle reads: "at_risk guest at 75% churn risk — 4 visits, last seen 2026-04-17"
- I wrote the suggested_action server-side in English in api/cron/proactive-comms.js
- Brazilian managers see English developer-template text on their dashboard
- **Fix**: generate suggested_action in restaurant's agent_language, OR move to client-side i18n + structured trigger_data only

### H4 — "Edit Floor Plan" button untranslated English
Floor plan section is fully PT-BR ("MAPA DE MESAS", "Ao Vivo", "Disponível", "Ocupada") except the edit button which says "Edit Floor Plan" in English. Hardcoded string with no i18n key.
- **Fix**: wire through t('host.editFloorPlan') with PT/EN/ES translations

### L2 — Dashboard 3s white-screen on initial load
